UPSC GURUKUL GAMES - folder guide
index.html            page shell (open this)
css/games.css         styling (uses the reader's colours and saved theme)
js/app.js             views, game modes, scoring, progress, achievements
data/catalogue.js     subjects and chapters (add a chapter title to a list)
data/questions.js     question bank: Q(chapter,difficulty,question,options,answerIndex,explanation)
data/activities.js    content for sort, ordering, true/false and pair/memory games

Game types: practice, timed, boss challenge (3 lives), fill in the blanks, sort into groups,
rapid true/false (60 s), chronology ordering, match the pairs, memory cards, review mistakes, daily challenge.
Chapter ids are the title in lowercase with dashes, e.g. "Fundamental Rights" = fundamental-rights.
All starter content is UNREVIEWED. Check each item against its source before relying on it.
Progress is stored only in this browser (localStorage). There are no leaderboards.
